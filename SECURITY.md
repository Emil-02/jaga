# Security Policy

`jaga` memindai file secara lokal. Nilai secret dan data pribadi tidak pernah dikirim ke server, tidak dicetak mentah, dan selalu disensor di keluaran laporan. Mode `--ci` hanya membaca; tidak mengubah repositori.

## Melaporkan kerentanan

Jangan buka issue publik untuk laporan kerentanan. Gunakan
[GitHub Security Advisories](https://github.com/Emil-02/jaga/security/advisories/new)
supaya detailnya tetap privat. Saya akan merespons dalam 7 hari.

## Dukungan

Versi `0.1.x` mendapat perbaikan keamanan. Selalu gunakan rilis terbaru.
